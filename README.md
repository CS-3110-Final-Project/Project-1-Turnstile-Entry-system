Description

This project uses a Deterministic Finite Automaton (DFA) to simulate a turnstile system. Users can enter by inserting a coin or scanning a pass. The system also handles unauthorized entry attempts and emergencies.

How to Run

Make sure Python 3 is installed.

Open the project folder in a terminal.

Run python turnstile.py

Follow the menu to interact with the system.

Features

Coin and pass entry

Unauthorized entry alarm

Emergency unlocking and reset

Input validation

Requirements

Python 3 (no additional libraries needed).
